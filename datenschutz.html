1. Datenschutz auf einen Blick

Allgemeine Hinweise

Die folgenden Hinweise geben einen einfachen Überblick darüber, was mit Ihren personenbezogenen Daten passiert, wenn Sie diese Website besuchen. Personenbezogene Daten sind alle Daten, mit denen Sie persönlich identifiziert werden können.

Datenerfassung auf dieser Website

Die Datenverarbeitung auf dieser Website erfolgt durch den Websitebetreiber (Kontaktdaten siehe Abschnitt „Verantwortliche Stelle"). Ihre Daten werden zum einen dadurch erhoben, dass Sie sie uns mitteilen (z. B. per Telefon oder E-Mail). Andere Daten werden automatisch beim Besuch der Website durch unsere IT-Systeme erfasst — vor allem technische Daten wie Browser, Betriebssystem und Uhrzeit des Seitenaufrufs.

Diese Website nutzt keine Analyse- oder Tracking-Dienste, setzt keine Marketing-Cookies und bindet keine Inhalte von Drittservern ein; Schriften und alle sonstigen Inhalte werden vom eigenen Server geladen (kein Google Fonts, keine Karten- oder Video-Dienste).

2. Hosting

Diese Website wird bei einem externen Hosting-Anbieter gehostet. Wenn Sie diese Website besuchen, erfasst der Hoster verschiedene Logfiles inklusive Ihrer IP-Adressen (Details siehe „Server-Log-Dateien"). Die Verwendung erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO — wir haben ein berechtigtes Interesse an einer möglichst zuverlässigen Darstellung unserer Website. Mit dem Hoster wird ein Vertrag über Auftragsverarbeitung (AVV) geschlossen.

Der Provider der Seiten erhebt und speichert automatisch Informationen in sogenannten Server-Log-Dateien, die Ihr Browser automatisch an uns übermittelt: Browsertyp und -version, verwendetes Betriebssystem, Referrer-URL, Hostname des zugreifenden Rechners, Uhrzeit der Serveranfrage, IP-Adresse.
